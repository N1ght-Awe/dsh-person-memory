# 发布包与数据范围

本仓库采用逐文件选入的发布方式：只包含通用模块、重写的合成测试与示例、接入文档及许可证。未复制原目录或原 Git 历史。

发布内容不包含生产配置、真实账号/群号/Session 映射、个人角色卡、聊天记录、记忆正文、向量库、日志、备份、凭据、私有报告或部署脚本。测试不从宿主环境加载这些数据。

公共 package 检查校验 RELEASE-MANIFEST.json 中的文件路径和 SHA-256，并检查常见凭据、个人目录、运行态文件与账号形态。它不能数学证明任何文本都没有敏感含义，也不能代替逐文件审阅。发布方还应在本机把候选文件与已知个人标识/密钥对照；这类私密对照表不能进入仓库。

贡献时：

1. 用合成账号、合成路径、合成事实和临时目录复现。
2. 不粘贴真实请求日志、cookie、token、数据快照或聊天截图。
3. 不把备份和诊断输出加入源码目录。
4. 修改文件后重新检查清单与测试；新增依赖或网络行为需要明确说明。
5. 对真实宿主的验证结论与本仓库的合成测试分别记录。

仓库不包含自动遥测、安装钩子、服务启动或停止脚本。核心桥接在真实接入时会通过使用者提供的传输和发送适配器通信，具体数据出机范围由宿主与网关决定。
