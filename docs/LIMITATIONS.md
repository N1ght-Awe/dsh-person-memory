# 已知限制

- 当前面向单个绑定用户和配置群；没有通用多租户隔离、自动注册或绑定 UI。
- Windows 目录规范化是现有身份实现的一部分。POSIX 系统可以运行合成测试，但真实路径接入需要适配。
- normal / secret 是规则分类。关键词会漏判和误判，不能识别任意隐私信息；仍需明确数据范围和宿主入口约束。
- secret 专用保存可以写入宿主本地存储，但不提供自动返值或群披露；不提供加密、凭据保管或本机认证 UI。
- 只在专用记忆命令路径拦截内容，不能保证任意普通聊天中的秘密不被模型或网关看到。
- 旧聊天、旧备份、平台消息和已有向量不会因这份模块自动清除。遗忘当前条目不等于全链路数据擦除。
- 自然语言解析和旧档案识别均为有限规则。重要操作宜使用 /记忆 命令；转述、复杂否定或语义歧义不保证正确解释。
- 发送前复查版本缩小了旧值发送窗口，但不是存储与外部平台之间的原子事务。复查与实际网络发送之间仍有竞争窗口。
- 请求去重基于平台消息关联，台账保留窗口约七天，并在接收新请求时清理旧条目。超过窗口的重复事件可能重新执行。
- 台账使用临时文件替换，不具备跨进程写入锁或断电级事务保证；崩溃后 pending/committing 的恢复治理未实现。
- 桥接认证密钥与 cookie 的验证依赖宿主；模块不是公网 API 网关。模型拥有任意文件/网络工具时，不能仅靠提示词构成隔离。
- 宿主所有写入入口必须递增版本，并过滤模型、导出、摘要与向量入口。只接一个接口不足以保证整体行为。
- 本仓库不包含上下文压缩引擎或 preset 改造，不声明通过长上下文模型压缩或真实 QQ 实收验收。
