# 验证范围

本发行版的独立测试使用 Node.js 原生测试运行器、临时目录、演示存储和本地捕获发送函数。

覆盖身份映射、当前/旧 Session、显式桌面绑定、子代理无绑定、群权限、角色变化、持久化重读、更正版本、遗忘、锁定删除、secret 模型视图过滤、歧义、配置开关、固定目的地、去重、取消、版本/删除复查、发送结果未知以及简短回复的否定和条件。

examples/demo.mjs 串联真实核心模块和演示存储，执行保存 → Session 变化 → 群查询 → 更正 → 请求私聊回复 → 遗忘。

tests/no-network.mjs 禁用常见 Node 网络发送入口，以防演示或测试意外连接服务。这个预加载器是测试防误触措施，不是恶意代码沙箱。

未在本发行包中验证：真实宿主认证、生产 MemoryStore、全部模型/导出/摘要/向量入口、真实平台实收、长上下文压缩、崩溃恢复或并发多写者。

不要将这些测试解释为通用安全审计或所有接入环境的兼容保证。重新运行测试是复核本仓库行为的依据。
